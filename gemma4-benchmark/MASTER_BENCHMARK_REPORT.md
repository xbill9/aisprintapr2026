## 📋 Project Scope
This report consolidates the performance characteristics of the **Gemma 4** model ecosystem self-hosted on **Cloud TPU v6e-4 (Trillium)** using the **vLLM** inference engine.

## 📊 Peak Performance Milestones
- **Prefill Throughput Ceiling:** **498,253 tokens/sec** (Achieved at 256 concurrent users).
- **Max Batch Payload:** Successfully processed ~**67 Million active tokens** in a single prefill injection (1024 users × 65,500 context).
- **Usable Scaling Limit:** The system demonstrates linear throughput scaling up to **256 users**, beyond which latency increases with marginal throughput gains.

## 🔍 Key Findings & Constraints
1.  **Physical Memory Limits:** The **Gemma-4-26B-A4B-it** model has a hard-coded physical context limit of **65,536 tokens**. All attempts to injection 128K context returned a `Status 400`.
2.  **bfloat16 Criticality:** Transitioning to `bfloat16` was required for both vLLM engine stability and memory efficiency on the Trillium architecture.
3.  **Optimal Operation Zone:**
    *   **Interactive (TTFT < 1s):** Up to 8 concurrent users at any context depth up to 16K.
    *   **Production RAG (TTFT 3-7s):** Up to 64 concurrent users at the full 64K context limit.
    *   **Batch Reasoning (TTFT 10-20s):** Up to 256 concurrent users at the full 64K context limit.
